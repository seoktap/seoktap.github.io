# 「석탑 읽기」 작성 안내

하루 1편, 국가유산청 검색 목록(`_data/pagodas.csv`, 511건, 연번 열 이름은 `num`)의 **연번(num) 순서**대로 한 기씩 글을 올립니다.

## 다음 글 정하기
- 글 파일은 `_posts/YYYY-MM-DD-stupa-NNN.md` 이며 NNN은 목록의 연번(세 자리)입니다.
- `_posts`에서 가장 큰 `stupa-NNN`을 찾아 **그 다음 연번**을 씁니다. 빠진 번호를 되메우지 않습니다.
- 머리말(front matter)은 `title`, `date`(게시일 18:30:00 +0900), `num`(연번을 따옴표로 감싼 문자열, 예: `num: "2"`), 그리고 조건이 되면 `model`(아래 3D 절) 을 씁니다. **키 이름은 반드시 `num`입니다.** YAML은 `no:`를 거짓(false)으로 읽어 버려 연결이 깨집니다. 종목·시대·지역 표지와 전체 목록의 '읽음' 표시는 `num`으로 자동 연결되므로 `num`이 틀리면 엉뚱한 탑으로 표시됩니다.
- 글 제목은 `[석탑 읽기 ②] 명칭 — 한 줄 요지` 형식입니다. 번호는 ①~⑳은 원문자, 21부터는 `[석탑 읽기 21]`처럼 숫자로 씁니다.
- 쌍탑이나 수량이 여러 기인 항목은 한 편에 함께 읽습니다. 석탑 자체가 아닌 유물(사리장엄구 등)이면 그 유물을 중심으로 읽되 형식은 같게 합니다.

## 글의 구성 (첫 글 `2026-10-25-stupa-001.md`를 본으로 삼습니다)
기본 정보 표(`_data/pagodas.csv` 값 그대로) → 한눈에 보기 → 이름·분류 문제 → 구조 읽기 → 조각·양식 읽기 → 이 탑이 겪은 일 → 보존 연구와 현재 상황 → 읽는 포인트 → 관련 논문과 자료 표 → 다음 글 예고 → 참고한 자료.
자료가 없는 대목은 억지로 채우지 말고 해당 절을 줄이거나 생략합니다. 본문은 `<div>` 하나로 감싸고 `<h2>`, `<table>`, `<ul>` 같은 기본 태그만 씁니다(스타일은 사이트가 입힙니다).

## 분량과 깊이
- 한 편은 첫 글처럼 **최대한 자세히** 씁니다. 본문 1만 자 안팎을 기준으로 하되, 자료가 얇은 탑은 억지로 늘리지 않고 확인된 만큼만 깊게 씁니다.
- 구조는 표(층수, 기단, 부재별 특징), 시대 비교(같은 시기·양식 탑과의 차이), 내력(건립·훼손·해체수리·이전), 보존과학·조사 연구 순으로 가능한 데까지 파고듭니다.
- 수치(높이, 층수, 연도)는 출처마다 다르면 표로 나란히 놓고 차이를 밝힙니다. 어느 쪽이 맞는지 단정하지 않습니다.

## 관련 논문 찾기 (매 편 필수)
- 글을 쓰기 전에 그 탑(또는 같은 양식·지역의 탑)을 다룬 논문을 검색합니다. 한국어·영어로 각각 찾고, 학술지 페이지, 대학·학회 저장소, DOI, 국립문화유산연구원 보고서 등을 봅니다. RISS·KCI·DBpia·Nate 등 로봇 접근을 막는 페이지는 우회하지 않습니다. 열린 곳(학회 사이트, DOI, 저장소, 검색 결과 요약)에서 확인되는 만큼만 씁니다.
- 글 끝에 `관련 논문과 자료` 표를 둡니다. 열: 저자·연도 / 제목 / 수록지 / **확인한 범위**(초록만, 본문 일부, 제목만 등). 확인하지 못한 논문의 결론은 쓰지 않습니다.
- 찾았으나 열리지 않은 논문은 "제목만 확인"으로 밝히고, 논문이 전혀 없으면 "검색했으나 이 탑을 직접 다룬 논문은 확인하지 못함"이라고 씁니다.
- 새로 읽은 논문이 이후 글에도 쓰일 만하면 `_source/논문메모.md`에 자기 말로 요약해 둡니다.

## 3D 모식 모델 (조건부)
- 머리말에 `model`을 넣으면 글 머리에 돌려 볼 수 있는 3D 뷰어가 붙습니다. 넣지 않으면 뷰어는 나타나지 않습니다.
- **층수·평면·기단 단수가 자료로 확인될 때만** 넣습니다. 확인이 안 되면 넣지 않습니다(추측으로 모델을 만들지 않습니다).
- 예:
  ```yaml
  model:
    tiers: 7          # 탑신(몸돌+지붕돌) 층수 1~15
    base_tiers: 2     # 기단 단수 1~4
    base_plan: square # 기단 평면 square | octagon | ya
    body_plan: square # 탑신 평면 square | octagon | ya
    ya_body_tiers: 0  # 아래에서 몇 층이 亞자형인지
    finial: true      # 상륜부가 남아 있으면 true
    stone: granite    # granite | marble
    height: 10        # 상대 높이(대개 10, 높은 탑은 12 안팎)
  ```
- 뷰어는 층수와 평면만 반영한 **모식 모델**이며 실제 조각·비례·훼손은 담지 않습니다. 뷰어 아래 안내문이 이를 밝히므로, 본문에서도 실물의 모습처럼 서술하지 않습니다.

## 자료와 사실 확인
- 기본 정보는 `_data/pagodas.csv`가 우선입니다. 국보·보물 지정 번호는 목록에 없으므로 국가유산포털이나 한국민족문화대백과에서 확인하고, 확인이 안 되면 번호를 쓰지 않습니다.
- 구조·연대·내력은 한국민족문화대백과, 국가유산청·국가유산포털, 지자체·학술 자료, 신뢰할 만한 기사에서 찾습니다. 한 출처만 믿지 말고, 출처끼리 다르면 어느 쪽이 맞다고 단정하지 말고 **차이를 본문에 밝힙니다**(예: 건립 연대, 복원 시기).
- 열지 못한 기사나 접근이 막힌 페이지의 내용은 쓰지 않습니다. 제목만 본 경우 그렇다고 밝힙니다.
- 문장을 그대로 옮기지 않고 자기 말로 풀어 씁니다. 직접 인용은 한 출처당 한 번, 15단어 미만으로만 합니다.
- 마지막에 참고한 자료를 링크와 함께 적습니다.
